# ReconX
A simple automated reconnaissance tool built for beginners in cybersecurity.

<img src="https://github.com/njengamoses/ReconX/blob/main/images/reconx_ui.png?raw=true" width="600" alt="ReconX UI">

## Features
- Scans IPs and ports using Nmap
- Generates clean HTML reports
- Easy to extend and modify

## Usage
python -m reconx.cli -t <target_ip>
